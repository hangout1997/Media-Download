# 開發歷史紀錄 (Development History Log)

## [2026-05-18] 伺服器資源清理機制相容
### 主要變更
* **加入全域伺服器清理清單**：此專案已納入全域伺服器資源管理範圍。當執行 `release-servers` 時，此專案在背景殘留的 Streamlit 服務進程將會被自動掃描並釋放。
* **建立開發歷史紀錄規範**：為追蹤專案成長，建立 `docs/DEVELOPMENT_HISTORY.md`。

## [2026-05-17] 擴充為「批次社群媒體下載器」與 RAM-First I/O 優化
### 主要變更
* **重構為批次處理架構**：將原本單一網址下載模式升級為支援批次網址提交、多媒體資源同時下載架構。
* **多媒體資源（Multi-Asset）支援**：重構媒體管道，單一社群網址（如 Instagram 貼文、Facebook 多圖文）現在可同時解析並下載多張圖片與多段影片。
* **主流社群平台完整支援**：全面串接並優化對 YouTube, Facebook, Instagram 等各大社群媒體的影片與圖片擷取邏輯。
* **UI 整合**：於 Streamlit UI 界面全新整合多媒體清單顯示，使用者能一目了然看見解析出來的所有相簿圖片與影片，並一鍵批量下載。
* **RAM-First I/O 記憶體管道**：遵循高效能讀寫指引，所有下載之影音媒體流均優先於記憶體（RAM）內處理，最大程度避免 SSD 寫入損耗與零碎 I/O。
* **Google Drive 自動同步**：完美整合已下載檔案的自動歸檔，迅速同步至 Google Drive 雲端工作流。
